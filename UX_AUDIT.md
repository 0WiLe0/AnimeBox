# AnimeBox — UI/UX-аудит

Проверка в реальном браузере (панель браузера + Playwright/Chromium), ширины 360–1440 px. Скриншоты «до» — [`audit/screenshots/before/`](audit/screenshots/before/), «после» — [`audit/screenshots/after/`](audit/screenshots/after/).
Критичность: **P0** блокирует сценарий · **P1** сильно мешает · **P2** заметно · **P3** косметика.

## Узнаваемые элементы дизайна (сохраняем)
Монохром `#212121` / белый, Oswald uppercase на страницах приложения и Comfortaa на auth, рамки 2px с радиусом 5px, вертикальная иконка-панель с «облачками»-подсказками, мотив трёх кружков, ч/б арт героев на welcome/auth, вертикальный логотип «Anime Box BETA», «шторка» загрузки на auth.

## Основной сценарий: вход → просмотр
`welcome` → «Начать просмотр» → **404** (`auth.html`) ⟶ сценарий обрывается на первом клике (P0). Даже открыв `login.html` вручную, «Войти» лишь перезагружает форму (P0). С главной «Смотреть» и «перейти к просмотру» никуда не ведут, меню перезагружает страницу (P0). В плеере — чёрный экран с технической ошибкой HLS (P0). **Итог: целевое действие «посмотреть серию» недостижимо ни одним путём.**

### Общие
- **Клавиатура:** нет видимого фокуса нигде (P1); интерактивные `div` (звёзды, «полная история», качество) недоступны (P1). Исправить: общий `:focus-visible`, семантические элементы, skip-link.
- **Состояния:** нет загрузки/ошибки/пустых состояний в плеере (P1), счётчики и прогрессы фиктивны (P3 — до бэкенда).
- **Типографика:** большинство длинных текстов — 12–14 px uppercase justify; мелкие теги 10 px (P2).
- **Контраст:** монохром даёт хороший контраст; проблема только в серых подсказках/плейсхолдерах (P3).
- **Единообразие:** кнопки трёх видов (заливка/контур/инверсия при hover) — ок, но размеры и высоты разнятся 32/45/49/51/65 px (P3 → токены).

## Точечные улучшения дизайна (без редизайна)
1. Сохранить монохром и Oswald; добавить один акцент только для состояний фокуса/ошибок.
2. Длинные тексты — обычный регистр, 15–16 px, выравнивание влево.
3. На мобильных иконка-панель → нижний таб-бар с теми же иконками в рамках 2px и подписями.
4. Высоты контролов свести к 44 / 52 px.
5. Карточки тайтлов — единый компонент с соотношением 2:3 вместо фикс. px.

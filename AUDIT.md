# AnimeBox — технический аудит

Дата: 02.11.2026 · База аудита: ветка `Frontend_Side` (самая полная: есть `anime.html` и обновлённый профиль).
Скриншоты «до»: [`audit/screenshots/before/`](audit/screenshots/before/) · сырые метрики: [`audit/report-before.json`](audit/report-before.json) · Lighthouse: [`audit/lighthouse/`](audit/lighthouse/).

Приоритеты: **P0** — сайт сломан / блокирует публикацию, **P1** — серьёзная проблема, **P2** — заметный недочёт, **P3** — косметика / техдолг.

## 1. Что есть в репозитории

| Ветка | Содержимое |
|---|---|
| `main` | `frontend/` — 6 страниц (welcome, login, register, main, player, profile), `ffmpeg.txt` |
| `Frontend_Side` | те же страницы в корне + `anime.html`, `source/css/anime/`, доработанный `profile.html`, `.gitignore` |
| `backend` | только `README.md` («Тестовая запись») — бэкенда нет |
| PR #1 | ссылка на `refs/pull/1/head`, в истории |

Стек: чистые HTML/CSS/JS, Google Fonts (Comfortaa, Oswald), Video.js 8.3 с CDN. Сборки, пакетного менеджера, тестов, линтеров нет.
Размер: ~66 МБ, из них **56 МБ — `source/video/2.mp4`** (фон главной) и 9 МБ — `op_kinok1.mp4`.

### Оценка стека
Для прототипа из 7 статических страниц стек уместен: фреймворк/сборщик сейчас не даст выигрыша и только усложнит хостинг. Переписывать на React/Vue **нецелесообразно** до появления реального API (каталог, авторизация). Рекомендация: оставить статику, вынести общий код (меню, сброс стилей, токены) в общие файлы, добавить минимальный инструментарий (http-server, Playwright, axe) — сделано в этом проходе.

### P3 — техдолг
- Inline-стили размеров в разметке (`style="width:187px;height:280px"`), `serif` как фолбэк для Oswald/Comfortaa.
- `ffmpeg.txt` лежит в корне сайта и уйдёт на хостинг — перенести в `docs/`.
- `.gitignore` игнорирует только `.idea`; `node_modules` нужно добавить.
- Скрипты подключены после `</body>` (невалидно, хоть и работает).

## 3. Незаконченные функции и заглушки
- Авторизация/регистрация — только UI; бэкенда нет (ветка `backend` пустая).
- Разделы «Рейтинг», «Каталог», «Настройки» — пунктов меню нет страниц.
- Кнопка «report» (треугольник) и «три точки» в меню — без действия.

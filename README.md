# 📺 AnimeBox — Frontend (UI Prototype)

**AnimeBox** — frontend-часть проекта стримингового аниме-сервиса.  
Данный репозиторий представляет собой **UI-прототип**, реализованный на чистом **HTML, CSS и JavaScript** без использования frontend-фреймворков.

Проект сфокусирован на дизайне, пользовательском опыте и структуре интерфейса будущего сервиса.

---

## 🧠 Описание

Frontend включает набор страниц, имитирующих работу полноценного аниме-сервиса:

- стартовая (landing) страница
- авторизация и регистрация
- главная страница
- профиль пользователя
- кастомный видеоплеер
- боковое навигационное меню

Проект может использоваться как:
- дизайн-прототип
- основа для дальнейшей интеграции с backend
- учебный frontend-проект

---

## ✨ Реализованный функционал

- 📄 Многостраничная структура
- 🎨 Полностью кастомный UI

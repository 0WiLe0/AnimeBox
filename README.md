# 📺 AnimeBox — Frontend

**AnimeBox** — это frontend-часть проекта стримингового аниме-сервиса.  
Данный репозиторий представляет собой **UI-прототип** интерфейса сервиса, реализованный на чистом **HTML, CSS и JavaScript** без использования фреймворков.


---

## 🧠 Описание

Frontend включает набор страниц, имитирующих работу полноценного аниме-сервиса:

- welcome / landing page
- авторизация и регистрация
- главная страница
- профиль пользователя
- кастомный видеоплеер
- навигационное меню

Проект может использоваться как:
- дизайн-прототип
- основа для дальнейшей интеграции с backend
- учебный frontend-проект

---

## ✨ Реализованный функционал

- 📄 Многостраничная структура
- 🎨 Полностью кастомный UI
- 🎬 Страница плеера с кастомными элементами управления
- 🔊 Управление громкостью
- ⏯ Play / Pause
- 📊 Прогресс-бар видео
- 🧭 Боковая навигация
- 🔐 Формы логина и регистрации (UI)
- 👤 Страница профиля пользователя

---

## 🛠 Используемые технологии

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **Video.js** (для видеоплеера)
- **Google Fonts**
- SVG-иконки
